{# The Markdown formatting toolbar (F38/F70, ADR-044) — shared by blog/editor.html and pages/shared_editor.html so the two never carry a duplicated block (T148). editor.js wires every button up generically off `.md-toolbar` / `.md-toolbar__button`, whichever page loaded it. `target_id` names the textarea `aria-controls` points at. The photo action is not one of these buttons at all (T149, F72) — it is its own visible control in `blog/editor.html`, outside this toolbar, because a photograph is not markup the other buttons write; the shared-article editor has no image pipeline (ADR-044) and so has no such control either — that is the toolbar's only remaining difference between the two editors. #}
